# Social Publisher V8 — iPhone PWA

Manuel ve toplu Facebook yayınlama sürümü. Planlama, AI otomasyonu veya içerik arşivi içermez.

## Deploy
`npx wrangler deploy`

Cloudflare üzerinde mevcut `META_APP_ID` ve `META_APP_SECRET` ayarlarını koruyun.

## iPhone
Siteyi Safari'de açın → Paylaş → Ana Ekrana Ekle.

Not: PWA uygulama gibi açılır; manuel paylaşım için internet bağlantısı gerekir.
